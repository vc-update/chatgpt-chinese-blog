# 关于本站

ChatGPT 中文指南关注中文用户在使用 ChatGPT 和其他主流 AI 工具时最常遇到的实际问题：官网入口怎么核对、网页版怎么用、登录为什么失败、文件和图片如何安全处理、Codex 如何安装，以及不同模型适合什么任务。

## 写作原则

- 先回答搜索者的问题，再补充背景和延伸阅读。
- 区分官方产品、教程博客、第三方平台和仿冒页面。
- 对会变化的模型、价格、账号和地区信息保留核验入口。
- 不使用隐藏文字、虚假评价、自动跳转或批量近义薄页。
- 推荐第三方服务时标明独立身份，不要求读者提供敏感凭据。

本站会持续修订文章，但更新时间只代表本站内容变更时间，不代表任何厂商在同一天发布了新版本或新政策。
