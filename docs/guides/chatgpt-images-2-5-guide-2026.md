## 一、ChatGPT Images 2.5 更新了什么

OpenAI 在 [《介绍 ChatGPT 图片 2.5》](https://openai.com/index/introducing-chatgpt-images-2-5/) 中介绍，Images 2.5 面向 ChatGPT、ChatGPT Work 和 Codex 用户，覆盖桌面端、移动端和网页版。官方称，Images 2.5 相比 Images 2.0 将图像生成延迟降低了最多 50%。

这次更新可以概括为：

- **更自然的光线和纹理**：画面中的材质、环境光和细节更丰富；
- **更好的参考图保留**：人物、商品和场景的主体特征更容易保持；
- **更精准的编辑**：只修改指定对象，尽量不影响其他区域；
- **更稳定的连续修改**：多次编辑后，早期调整不容易被后续指令覆盖；
- **更适合创意流程**：Sketch、海报模板、周边模板和提示词分享让创作更容易开始和复用。

## 二、参考图保真与精准编辑怎么用

### 1. 先上传参考图，再说明“保留什么”

Images 2.5 更适合从一张参考照片出发做变体。提示词不要只写“把它变得更好看”，而要明确主体、构图和不能改变的内容。

```text
以我上传的产品照片为唯一主体参考。
保留产品的外形、按钮位置、接口数量、品牌颜色和正面视角。
把背景改成浅灰色工作室背景，加入柔和的左侧自然光。
产品占画面约 60%，右侧留出干净区域用于后期添加标题。
不要增加其他产品、Logo、二维码或额外文字。
```

### 2. 做局部编辑时只描述一个变化

如果只想改背景、衣服颜色或一段文案，应该明确“其他部分保持不变”。这样更容易利用 Images 2.5 的精准编辑能力。

```text
只修改背景：将室内灰色背景改为明亮的米白色墙面。
保留人物姿势、脸部特征、服装、光线方向和画面比例不变。
不要添加家具、文字、Logo 或新的装饰物。
```

对于商品图，建议把“必须真实”的细节列出来，例如型号、接口、按键、包装尺寸和颜色。不能让模型自由发挥这些信息。

## 三、多轮编辑如何保持一致

Images 2.5 针对较长的 ChatGPT 对话改进了多轮编辑一致性。实际使用时，建议把每轮修改控制在一个变量内，并在提示词中重复保留项。

推荐的迭代顺序：

1. 第一轮确定主体、视角和画面比例；
2. 第二轮调整背景、光线和色彩；
3. 第三轮加入短标题或行动提示；
4. 第四轮修改一个局部细节；
5. 最后一轮检查文字、尺寸和边缘裁切。

示例：

```text
在上一版基础上只做一项修改：
把背景中的蓝色改为品牌青绿色，保持人物、产品、文字、构图和光线不变。
不要重新安排布局，不要新增元素，不要修改标题。
```

如果一次同时要求换背景、改人物、加文字和裁剪比例，出现不可预测变化的概率会更高。保留每轮提示词，也方便回退到上一版。

## 四、Sketch 和模板功能怎么用

### Sketch：先画出大致结构

OpenAI 推出的 Sketch 允许你直接在 ChatGPT 中画草图，再把草图当作视觉参考。它适合画房间布局、服装轮廓、海报分区或产品摆放位置。使用时可以在 ChatGPT 中输入“@Sketch”，再补充风格、材质和用途。

```text
@Sketch
请把这张草图转换成一张竖版科技产品宣传海报：
保留草图中的三栏结构和顶部标题区；
主色为深蓝，青绿色用于按钮和小面积强调；
画面干净、适合手机信息流，不要添加草图中没有的品牌 Logo。
```

### 模板：从常见格式开始

Images 2.5 提供海报、周边等创意模板。模板的价值不是替你完成所有设计，而是先确定信息区域和视觉比例。选好模板后，仍要补充受众、主标题、产品主体、颜色和禁止项。

```text
使用“海报”模板，制作一张竖版 AI 办公工具发布海报。
主标题：把重复工作交给 AI
副标题：从资料整理到报告初稿，一次完成
主体：整洁办公桌上的笔记本电脑和文档卡片
风格：专业、明亮、留白充足；主色深蓝，强调色青绿色。
只出现以上两行中文，不添加其他文字、二维码或水印。
```

## 五、职场图片创作的提示词模板

### 1. 宣传海报

```text

受众：希望提升工作效率的职场用户
主体：办公桌、笔记本电脑、文件和柔和屏幕光
构图：主体位于下半部分，顶部留出标题区
风格：现代、专业、真实摄影；深蓝与青绿色配色
文字：主标题“AI 办公效率分享会”，副标题“把重复工作交给合适的工具”
要求：只出现以上文字，不要乱码、额外 Logo、二维码或水印。
```

### 2. 商品图

```text

场景：浅色工作室背景，产品放在画面中央偏左，右侧留白。
光线：柔和侧光，材质清晰，避免过度反光。
图片中不要生成新的文字、价格、Logo、二维码或促销标签。
```

## 六、API 中的两个 Images 2.5 模型

OpenAI 官方介绍了两个新的 API 图像模型：

| 模型 | 适合场景 | 选择思路 |
| --- | --- | --- |
| `gpt-image-2.5-flare` | 创作者工具、社交内容、产品体验、视觉搜索、快速原型和批量生成 | 质量、编辑能力和速度更均衡，适合作为多数应用的默认选择 |
| `gpt-image-2.5-sunburst` | 高端创意、精细编辑、活动视觉和精致产品图 | 更强调编辑控制和最终画面精度，可以接受更长生成时间 |

开发者接入前，应查看 [OpenAI API 图片文档](https://developers.openai.com/api/docs) 和 [官方价格页面](https://developers.openai.com/api/docs/pricing)，确认请求格式、图片尺寸、速率限制和账单规则。不要把 API 密钥放在浏览器前端或公开仓库。

一个调用设计思路是：先用 Flare 快速生成多个构图方向，再用 Sunburst 对选中的方向做最终精修。无论使用哪个模型，都应保留原始参考图、提示词和版本记录。

## 七、可用范围与发布前检查

官方页面显示，Images 2.5 将向 ChatGPT、ChatGPT Work 和 Codex 的桌面端、移动端、网页版用户推出。实际显示时间仍可能受到账户、工作区和产品版本影响。

发布图片前建议检查：

- 中文标题、日期、数字和品牌名称是否逐字正确；
- 产品形状、人物特征和参考图主体是否被误改；
- 是否出现未要求的 Logo、二维码、水印或虚构信息；
- 图片尺寸是否适合公众号、信息流、PPT 或打印渠道；
- 上传的参考图是否含有客户姓名、订单号、地址或其他敏感信息；
- 商业发布是否已确认素材授权、肖像权和商标使用范围。

如果文字很重要，建议先生成无字底图，再用设计软件添加最终文案。Images 2.5 的文字能力有所提升，但重要物料仍应人工校对。

## 八、常见问题

### ChatGPT Images 2.5 和 Images 2.0 有什么区别？

Images 2.5 重点提升参考图保真、局部编辑、多轮一致性、复杂风格理解和生成速度，并增加 Sketch、模板和带提示词分享等产品功能。

### Images 2.5 能不能只修改图片中的一个对象？

可以尝试。提示词中要明确指出只修改哪个对象，并列出需要保持不变的主体、构图、光线和文字。复杂图片仍建议分轮处理。

### Sketch 适合什么任务？

适合快速表达布局和构图，例如房间平面、海报分区、服装轮廓和产品摆放。草图越清楚，模型越容易理解你的意图。

### Flare 和 Sunburst 怎么选？

Flare 更适合速度和批量生成，Sunburst 更适合精细编辑和高要求创意交付。可以先用 Flare 探索方向，再用 Sunburst 完成最终版本。

### 为什么连续修改后画面还是会变化？

生成具有随机性，输入图片、提示词、模型版本和编辑范围都会影响结果。每轮只改一个变量，并重复写明保留项，通常比一次提出很多修改更稳定。

## 总结

ChatGPT Images 2.5 的使用重点不是把提示词写得越来越长，而是把参考图、保留项、修改项和输出渠道说清楚。先用 Sketch 或模板确定结构，再用分轮编辑完善画面；需要批量探索时选择 Flare，需要精细交付时考虑 Sunburst。最后通过人工校对和授权检查，把生成结果变成真正可发布的图片。
