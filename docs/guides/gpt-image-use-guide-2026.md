## 一、图片提示词的六个要素

不要只写“做一张好看的海报”。可以按下面的顺序描述：

| 要素 | 需要说明什么 | 示例 |
| --- | --- | --- |
| 主体 | 画面中最重要的对象 | 一杯透明玻璃瓶装的柠檬茶 |
| 场景 | 对象处于哪里 | 夏日户外木桌，背景有绿叶 |
| 构图 | 视角、位置和留白 | 三分法构图，右侧留出标题区域 |
| 风格 | 视觉方向和材质 | 清爽商业摄影，柔和自然光 |
| 文字 | 文案、语言和位置 | 只放“夏日柠檬茶”，顶部居中 |
| 输出 | 比例、尺寸和用途 | 适合手机信息流封面，竖版比例 |

一个可复制的基础模板：

```text
请生成一张用于[用途]的图片。
主体：[对象、数量、材质、颜色]
场景：[地点、时间、背景]
构图：[视角、主体位置、留白区域]
风格：[摄影/插画/平面设计/写实等]
文字：[准确文案、语言、位置；不需要的文字写“不要添加文字”]
输出：[横版/竖版/方形、目标平台]
禁止：[多余人物、乱码、Logo、夸张反光等]
```

## 二、中文文字排版为什么要单独说明

图像模型可能会把汉字生成得不准确，尤其是长句、细小文字、品牌名和复杂表格。为了减少返工：

1. 海报只放一句短文案，不要一次塞入整段说明。
2. 把文字内容放在引号中，并明确“只出现这些字”。
3. 指定文字位置、字号层级和留白，不要只说“排版好看”。
4. 第一轮先验证主体和构图，第二轮专门修文字。
5. 重要宣传物料最终用设计软件重新排版，人工检查错别字和商标。

如果文字准确性比画面创意更重要，可以先生成无字底图，再在图像软件中添加文字。

## 三、真实场景示例：生成小红书封面

```text
生成一张竖版生活方式封面图，用于介绍“用 AI 整理旅行计划”。
主体：桌面上的笔记本、地图、咖啡和手机，不出现真实品牌 Logo。
场景：明亮的窗边书桌，背景简洁，有少量旅行元素。
构图：主体位于下半部分，上方留出明显空白用于后期加标题。
风格：自然光、清爽、真实摄影，不要过度饱和。
文字：图片中不要生成任何文字。
禁止：人物脸部、护照号码、二维码、乱码、虚构品牌标志。
```

这个提示词把“画面”和“文字”分开，后期更容易控制，也避免把个人证件或真实二维码带进图片。

## 四、商品图和人物图的隐私检查

### 商品图

上传商品原图前，确认图片中没有订单号、仓库地址、客户姓名、内部标签和未公开包装。生成商业图片时，不要让模型擅自修改必须真实的规格、接口、颜色或安全标识。

### 人物图

使用真人照片要确认本人授权。不要把儿童、证件照、员工头像或客户照片上传到未核实的平台，也不要用生成图冒充真实人物或真实事件。

### 品牌和版权

Logo、字体、角色、摄影作品和产品外观可能受权利保护。商业发布前要确认素材来源、使用许可和平台规则，不能因为图片由 AI 生成就忽略版权和商标问题。

## 五、怎样迭代，而不是每次全部重写

第一轮只检查三件事：主体是否正确、构图是否可用、风格是否符合用途。然后用短指令逐项修改：

- “保留主体和视角，只把背景改成浅灰色。”
- “保留人物姿势，只减少背景中的物体。”
- “不改变产品形状，只把光线改成柔和的侧光。”
- “保持画面比例，在左侧增加留白，不添加新文字。”

每次只改一个变量，比较结果时才知道哪条指令产生了影响。

## 六、尺寸和格式怎么选

具体可用尺寸以当前工具页面为准，但选择思路可以先固定：

| 用途 | 优先考虑 |
| --- | --- |
| 手机信息流封面 | 竖版构图，主体不要贴边 |
| 文章头图 | 横版构图，标题区域留白 |
| 社交头像 | 方形构图，主体居中且缩小后仍清楚 |
| 商品详情图 | 保留产品真实比例，避免模型改变关键细节 |
| 打印海报 | 先确认分辨率、出血和后期排版要求 |

不要把屏幕预览直接当成印刷成品，也不要在没有检查分辨率的情况下放大后用于商业印刷。

## 七、错误与避坑清单

- 一次要求长段中文、复杂表格和多个 Logo，导致文字错乱。
- 没有说明用途和比例，生成后才发现主体被裁切。
- 让模型自由修改商品规格、包装文字或安全标识。
- 上传含身份证、二维码、客户照片和订单信息的原图。
- 把 AI 生成的人物图当作真实新闻或真实客户案例发布。
- 只看画面好不好看，不检查错别字、手指、数字和品牌标识。
- 把第三方绘图平台当成官方图像服务，不阅读其数据政策。

## 常见问题 FAQ

### GPT 图片生成能准确写中文吗？

短文字通常比长段落更容易控制，但不能假设每次都完全正确。重要海报建议生成无字底图后人工排版，并逐字校对。

### 如何让图片中不要出现文字？

在提示词中明确写“不要添加任何文字、Logo、标识或水印”，同时给主体留出后期排版空间。仍需检查生成结果，因为模型可能自行加入装饰性文字。

### 可以上传自己的商品图进行编辑吗？

要先确认你拥有使用和处理该图片的权利，并删除订单号、客户信息和内部标签。第三方平台还需要单独核对文件保留和删除机制。

### AI 生成的人物图可以当证件照吗？

不建议把生成图当作真实身份凭证或官方材料。证件、签证、考试和求职场景应使用符合要求的真实照片，并以相关机构规则为准。

### 为什么同一个提示词生成的图片不一样？

生成具有随机性，模型版本、账号权限和编辑上下文也可能变化。可以固定提示词、尺寸和参考图，再一次只修改一个变量进行比较。

### 商业使用 AI 图片需要注意什么？

检查输入素材的授权、输出中出现的品牌或角色、平台条款和目标渠道要求。AI 生成并不自动消除版权、肖像和商标风险。
