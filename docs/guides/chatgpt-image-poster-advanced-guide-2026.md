## 一、先把海报需求说清楚

很多“画面不对”的问题，其实在生成前就已经出现了：活动对象不明确、受众不明确、主标题太长，或者一张图同时承担了太多任务。

可以先用一段话写清楚以下内容：

- **用途：** 招聘、活动报名、产品发布、内部培训，还是社交媒体传播；
- **受众：** 客户、合作伙伴、员工、管理层或普通用户；
- **唯一重点：** 读者看完最应该记住什么；
- **行动提示：** 报名、咨询、试用、扫码或了解详情；
- **画面气质：** 稳重、专业、亲切、科技感或轻松；
- **不能出现：** 不相关人物、复杂背景、错误数字和无关 Logo。

### 示例 Prompt

```text
我要制作一张企业线上分享会宣传海报。
用途：发布在微信公众号和企业微信群。
受众：希望了解 AI 办公方法的职场用户。
唯一重点：突出“AI 办公效率分享会”。
行动提示：报名参加线上直播。
画面气质：专业、清晰、可信，但不要沉闷。
请先给出 3 种不同的构图方案，每种方案说明主体、留白位置和适合放置的文案区域，不要直接生成最终海报。
```

先让 ChatGPT 给方案，能帮助你在动手生图前发现需求冲突，也更容易和同事确认方向。

## 二、先做构图，不急着塞文案

宣传海报首先是一个画面，其次才是文字载体。第一轮建议只要求模型解决主体、视角、位置和留白，不要一次加入日期、地点、嘉宾、二维码和长段说明。

构图时可以明确：

- 主体放在左侧、右侧、中央还是下方；
- 画面采用横版、竖版还是方形；
- 哪一块区域留给标题，哪一块区域留给行动提示；
- 观看者第一眼应该从哪里开始看；
- 背景需要简洁到什么程度。

### 示例 Prompt

```text
生成一张竖版企业宣传海报底图，比例适合手机信息流。
主题：AI 办公效率分享会。
画面主体：一张整洁的办公桌、笔记本电脑、便签和柔和的屏幕光，不出现真实品牌 Logo。
构图：主体放在下半部分，右上方留出约三分之一的干净空间，方便后期添加标题。
风格：现代、专业、明亮，颜色以深蓝和青绿色为主。
图片中不要出现任何文字、数字、水印、二维码或人物脸部。
```

这一轮的判断标准只有三个：主体是否正确、留白是否够用、画面是否符合宣传场景。不要因为细节还没完成就急着推翻整张图。

## 三、用视觉层级安排重点

一张海报通常需要同时放标题、副标题、时间、地点和行动提示。为了避免所有内容都在“抢注意力”，可以先把信息分成三层：

1. **第一层：** 读者必须立刻看到的主标题；
2. **第二层：** 帮助理解活动内容的副标题或一句说明；
3. **第三层：** 日期、地点、报名方式等辅助信息。

在 Prompt 中直接告诉模型层级，比只说“排版高级”更有效。主标题要短，行动提示要明确，辅助信息则尽量压缩。

### 示例 Prompt

```text
请在上一张海报底图上加入少量中文信息，并保持原有主体和构图不变。
第一层主标题：AI 办公效率分享会
第二层副标题：把重复工作交给合适的工具
第三层信息：周四 20:00｜线上直播
行动提示：立即报名
排版要求：主标题最大、放在右上方留白区；副标题放在标题下方；日期和行动提示靠近底部；只出现以上文字，不添加其他字。
整体保持简洁，文字与背景有明显对比，不要出现乱码、错别字、额外 Logo 或水印。
```

如果文字出现错误，不要马上要求模型重做整张海报。下一步只处理文字区域，或者生成无字底图后在设计软件中排版。

## 四、让品牌风格保持一致

职场海报常常不是只做一张，而是要做活动预告、倒计时、回顾和社交媒体封面。与其每次重新描述“好看”，不如先建立一份简单的风格卡：

| 项目 | 示例写法 |
| --- | --- |
| 主色 | 深蓝为主，青绿色作小面积强调 |
| 背景 | 纯色或轻微渐变，保持干净 |
| 字体感觉 | 清楚、稳重、适合屏幕阅读 |
| 图片质感 | 柔和光线、真实办公场景 |
| 构图习惯 | 主体靠下，顶部留标题区域 |
| 禁止元素 | 复杂纹理、夸张发光、无关图标 |

### 示例 Prompt

```text
请把这张海报调整为统一的品牌视觉：
主色使用深蓝，青绿色只用于按钮和小面积强调；
背景保持简洁，使用很轻的渐变；
办公桌和电脑保持真实比例，不增加新的设备；
光线柔和，画面清楚，适合企业公众号配图；
保留标题区域和主体位置，不改变海报比例；
不要加入霓虹光、复杂纹理、卡通贴纸或额外品牌标志。
```

这类风格卡还可以复用到下一张海报。每次只改活动主题和文案，颜色、留白和画面气质保持稳定，整个活动的视觉会更像一个系列。

## 五、用短 Prompt 分轮修改

进阶使用的重点是“每轮只改一件事”。如果同时修改人物、背景、颜色、文字和比例，你很难判断是哪条指令带来了变化。

可以按下面的顺序迭代：

1. 第一轮确认主体和构图；
2. 第二轮确认颜色和光线；
3. 第三轮加入短文案；
4. 第四轮修正局部细节；
5. 最后一轮检查尺寸和发布渠道。

### 示例 Prompt

```text
保留海报的主体、视角、颜色和文字不变，只做一项修改：
把右上方标题区域扩大一些，让标题周围多出约 20% 的留白。
不要移动办公桌，不要改变背景，不要添加新元素，不要修改任何文字。
```

与“请整体变得更高级”相比，短而具体的修改更容易得到可比较的结果。建议把每轮 Prompt 保存下来，方便回到上一版或复用到下一张海报。

## 六、处理海报中的中文文字

中文长句、数字、日期和品牌名是最容易出错的部分。要提高成功率，可以遵循三个做法：

- 主标题控制在一到两行，尽量使用短句；
- 日期、地点和行动提示分开写，不要塞进一整段；
- 重要物料先生成无字底图，再用设计软件或网页编辑器添加最终文字。

### 示例 Prompt

```text
请只修正海报中的文字，不改变人物、办公桌、背景、颜色和构图。
主标题必须是：AI 办公效率分享会
副标题必须是：把重复工作交给合适的工具
底部信息必须是：周四 20:00｜线上直播
按钮文字必须是：立即报名
除以上四行外不要出现任何文字、数字、Logo 或水印。
请逐字保留中文标点，不要改写文案，不要增加英文。
```

即使模型看起来已经生成正确，也要逐字检查。宣传海报中的一个错别字、日期错误或活动名称错误，都可能直接造成返工。

## 七、针对不同渠道准备尺寸

不要用同一张图硬裁所有平台。先确定投放位置，再让 ChatGPT 调整画面重心和留白。

| 使用渠道 | 构图建议 | 检查重点 |
| --- | --- | --- |
| 微信公众号头图 | 横版，主体不要贴边 | 标题在手机上仍清楚 |
| 企业微信群分享 | 竖版或方形 | 缩小后主标题仍可辨认 |
| 小红书封面 | 竖版，上方留标题区 | 重点不被界面按钮遮住 |
| PPT 内页 | 横版，左右留出安全边距 | 投影时颜色不过暗 |
| 打印海报 | 先确认纸张和分辨率 | 不直接把网页预览当印刷稿 |

### 示例 Prompt

```text
保留海报的主体、文案和品牌颜色，把画面改成适合企业微信群分享的方形构图。
让主标题保持在视觉中心附近，人物和电脑不要被裁掉，四周留出安全边距。
不要拉伸主体，不要添加新的文字、Logo、二维码或装饰元素。
```

如果同一活动需要多个尺寸，建议以一张构图最完整的母版为基础，分别调整留白，而不是让模型从零生成三张完全不同的图。

## 八、发布前做一遍交付检查

海报完成后，不要只看“好不好看”，还要按发布任务检查：

- 标题、日期、时间和地点是否准确；
- 主体是否符合活动或产品的真实情况；
- 是否出现多余人物、乱码、错误 Logo 或虚构按钮；
- 手机缩小查看时，主标题是否仍然突出；
- 画面四周是否有足够边距；
- 图片格式和尺寸是否满足发布平台要求；
- 是否需要把最终文字重新排版，以确保每个字准确。

### 示例 Prompt

```text
请不要重新生成海报，只做交付前检查。
请按表格列出：检查项目、发现的问题、建议修改。
重点检查：中文文字、数字和日期、主体比例、标题可读性、边缘裁切、额外 Logo、二维码和水印。
如果无法确认某一项，请写“需要人工确认”，不要自行猜测。
```

这一步适合让 ChatGPT 帮你找遗漏，但最终发布前仍应由负责活动的人确认文案和事实。


## 常见问题 FAQ

### 为什么 Prompt 写得越长，海报不一定越好？

因为过多要求可能互相冲突。先确定主题和构图，再分轮加入颜色、文字和细节，比一次写完所有要求更容易控制。

### ChatGPT 生成海报时，中文文字总是出错怎么办？

把主标题缩短，要求只出现指定文字；如果仍不稳定，就生成无字底图，再用设计工具添加文字。

### 可以直接让 ChatGPT 仿照某个品牌海报吗？

可以描述你需要的色彩、构图和信息层级，但更稳妥的做法是建立自己的风格卡，不要只依赖“做得像某某品牌”这种模糊要求。

### 一张宣传海报应该生成多少个版本？

先生成 3 个构图方向，再从中选 1 个深入修改。版本太多会增加比较成本，也容易让团队失去统一方向。

### GPTCat 在这套流程里适合做什么？

如果你想在国内直接使用 MJ，可以把 GPTCat 用作另一种图片生成和多轮创作工作台；具体入口和功能以其当前页面说明为准。本文的提示词方法同样可以迁移到其他图片工具。

## 总结

职场宣传海报的进阶方法可以概括为：先定义任务，再确定构图；先做画面，再处理文字；每轮只改一个变量；最后按渠道和内容逐项检查。这样既能提高 ChatGPT 原生生图的可控性，也能让同一套视觉更容易扩展成一组宣传物料。
